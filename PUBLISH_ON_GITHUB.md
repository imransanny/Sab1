# TOMATO Clothing — Ivory Edition

This ZIP contains a GitHub Pages-ready self-contained `index.html`. Images, CSS, and JavaScript are embedded inside this one file. No npm or build step is required.

## Publish
1. Extract the ZIP and upload ONLY `index.html` to the root of your GitHub repository (replace the previous `index.html`).
2. Go to **Settings → Pages**. Choose **Deploy from a branch**, branch `main`, folder `/(root)`. Save.
3. Visit `https://YOUR_USERNAME.github.io/YOUR_REPOSITORY/` after GitHub Pages finishes publishing.
4. Hard-refresh your browser if you still see the previous colours (mobile Chrome: open a private/incognito tab).

## Features
Themed homepage, six circular categories, featured pieces, New Arrivals, editorial section, shop, product detail, search, sort, wishlist, cart, and mobile menu. Hash URL navigation works on GitHub Pages.
